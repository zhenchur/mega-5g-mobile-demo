# Проверка и передача

Дата приёмки: **5 сентября 2026**. Текущие desktop и mobile проверены в **Microsoft Edge / Chromium на Windows**: **36 из 36 регрессионных сценариев проходят**. Проверка типов, обычная production-сборка и сборка GitHub Pages проходят.

[Публичное демо](https://zhenchur.github.io/mega-5g-mobile-demo/) доступно для разработчиков. В опубликованной версии проверены обе версии страницы, видимость контента и загрузка ресурсов; ошибок JavaScript, HTTP и изображений не обнаружено.

## Что проверено

| Область | Проверка |
|---|---|
| Навигация и доступность | Tab от промо до профилей и radio; начальные якоря; сохранение позиции при reload |
| Фокус и анимация | Видимость родителя и вложенного ряда при reverse, смене reduced motion и resize; сброс после blur и повторный вход |
| Mobile-галереи | Ось и порог жеста, один шаг, отпускание за границами, touch, tap, radio и вертикальный scroll |
| Connect | Клавиатура, частое переключение, inert/ARIA, crossfade и высота активной панели после resize |
| Scroll и responsive | Пороги 95%/85%, видимость технологий, стык секций, reduced motion, смена breakpoint и отсутствие горизонтального переполнения |
| Визуальная композиция | Сверка с Figma; mobile 320–430 px, desktop 1280–1920 px; отступы footer/FAQ и градиент Connect |
| Сборка | Типы приложения и QA, build, build:pages и загрузка ресурсов по GitHub Pages subpath |

## Повторить проверку

```bash
npm ci
npx playwright install chromium
npm run qa
npm run typecheck
npm run build
npm run build:pages
```

QA запускает отдельный Vite на `127.0.0.1:5187`. Команда `npm run qa:report` открывает локальный HTML-отчёт. Порядок запуска, включая использование установленного Edge, описан в [tests/README.md](../tests/README.md).

## Границы демо и приёмки

- Физические iPhone/Safari, Android и macOS Safari не проверялись. Touch-эмуляция не подтверждает аппаратную плавность и поведение browser bars; FPS не измерялся.
- Tablet 768–1279 px показывает согласованную заглушку.
- FAQ демонстрирует вход четырёх строк: первая раскрыта, остальные отключены. Оформление услуги, авторизация, меню и бизнес-переходы требуют продуктовой реализации.
- Исходные растры служат визуальным референсом. Responsive-форматы, бюджет загрузки и испытания на слабых устройствах относятся к продуктовой интеграции.
- Длительность нативного smooth scrolling ряда длительностей выбирает браузер.
